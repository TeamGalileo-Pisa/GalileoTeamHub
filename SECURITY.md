# Sicurezza

## Segnalazioni

Non aprire issue pubbliche contenenti credenziali, token, dati dei candidati o
informazioni sulle vulnerabilità. Contattare privatamente gli amministratori del
Team Galileo.

## Regole operative

- Non committare file `.env` o export del database.
- Non usare chiavi `service_role` nel frontend o su Netlify build-time.
- Considerare compromessa qualsiasi password condivisa in chat o documenti.
- Creare password iniziali uniche e sostituirle al primo accesso.
- Eseguire i test RLS e il test di concorrenza prima di ogni rilascio.
- Revocare e rigenerare immediatamente booking link o chiavi esposte.
